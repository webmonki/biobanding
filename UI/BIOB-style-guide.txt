Design Guide

In this document, you will find guidelines for which colors, fonts and design elements to use in the contect of Bio-Bending.

Since the Material Template is used most design elements are predetermined.

Fonts:

- Roboto(use for long text)
- Roboto Confused(use for Headlines or UI elements)
- Roboto Mono(use for tables)

Colors:

Classic Blue (Primary Color)

    #34538A
    rgb(52,83,138)
    hsl(218.4,45.3%,37.3%)
    cmyk(62,40,0,46)

Use for

    main design elements in marketing copy (eg. headlines or backgrounds)
    primary buttons
    links/actions
    highlights (like selections or active navigation item)

    dark background
